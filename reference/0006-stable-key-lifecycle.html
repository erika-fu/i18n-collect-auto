稳定 key 生命周期速查

面向自动 key、metadata v3、本地化调用、生命周期转换与安全失败处理的精简操作指南。

身份术语

本地化 key
运行时/catalog 标识符：显式 key 或 auto.<ULID>。
Occurrence 身份
用于恢复自动 key 的稳定 metadata 记录。
结构锚点
semanticHost + childRole + localContext。
源码位置
当前路径、语义 kind 与半开区间范围。它用于定位，不能独立证明身份。
规范源文本
保留在 catalog metadata 中的源文本和 fingerprint，即使活动 occurrence 都是本地化调用也一样。

自动 key 决策表

情形结果
新的未设 key occurrence分配不透明的 auto.<ULID>。
唯一的历史锚点匹配复用历史自动 key。
未匹配 occurrence分配避开已保留历史身份的新 key。
存在多个可行的历史候选写入歧义报告；失败并保留正式输出。
重试相同歧义锚点仍匹配时复用此前建议 key。
已确认的歧义使用显式指令或确认清单，然后发布。

Metadata v3 要点

{
  version: 3,
  entries: {
    "auto.01...": {
      source, fingerprint, origin,
      representation: "source-text" | "localized-call",
      status: "active" | "orphaned",
      locations, occurrences
    }
  }
}
  • 成功收集时发生 v1 → v2 → v3 升级。
  • 既有本地化 key 和 occurrence 身份会被保留。
  • v2→v3 默认补充 source-text representation。
  • replacements.json 是审计/回滚数据，不是自动 key 的恢复权威。

本地化调用策略

引用策略
t('key')、$t('key')、this.$t('key')仅识别静态、非空字符串 key 参数。
既有活动 key保持 active 并添加调用 occurrence。
未退役的孤立 key恢复为 active。
未知或已退役的项目 key收集失败。
externalKeys 成员允许，但不创建 catalog 条目。
旧 MD5 key兼容调用，置于带 key 的 catalog 之外。
共置指令的 key 不同收集失败。

生命周期与输出安全

active source-text → replace → active localized-call active → occurrence 消失 → orphaned orphaned → 有效调用 → active（恢复） orphaned → 确认/prune → retired（从 metadata 移除） retired → 调用 → 失败轮次

解析错误、格式错误的指令、key 冲突、身份歧义或无效调用引用，都会保留最近一次成功的哈希字典、source map、源 catalog 与 metadata。请解决原因；不要手动发布部分 catalog。
