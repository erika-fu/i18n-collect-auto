Loader 收集链速查

定位“某段中文为什么被收集/遗漏”时，按调用链逐层检查。

调用链

pitch → runCollect → loadConfig/trackConfig → canonicalPair → describeResource → isResourceIncluded → collectedFor → extractor → snapshotFor → record → module.buildInfo + session.submit → Plugin done → assemble/recover → buildCatalog → writeOutputs

资源分派

资源extractorkind
JS/TS/JSXextractScriptscript-string / template-literal
Vue scriptextractVueScript → extractScriptscript-string / template-literal
Vue templateextractHtmlhtml-text / html-attribute / template-expression
HTMLextractHtmlstatic-html-text / static-html-attribute
CSSextractCsscss-generated-content

五个判断点

  1. 是否真的进入 myloader？Plugin 不扫盘。
  2. Resource identity 是否含正确 block、style index、lang？
  3. include 放行且 exclude 未否决吗？
  4. 片段含 Han 且未被 directive/context filter 排除吗？
  5. 本轮 Compilation、catalog 校验和事务写入都成功了吗？

关键不变量

  • Loader transparent：source、sourceMap、meta 原样传递。
  • 每个 identity 是完整 snapshot 替换，空 snapshot 也有效。
  • Module metadata 供 cache 恢复；Session candidate 供本轮发布。
  • 失败 round 不发布部分 dictionary/catalog。
  • hash key 是 MD5(text)，不是 localization key。
