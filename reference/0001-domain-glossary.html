项目术语表

以 CONTEXT.md 为准。术语稳定，讨论实现时不要随意换同义词。

收集域

Collected text（已收集文案）
从源码识别出的中文候选用户文案；收集阶段只记录，绝不改写源码。
Semantic kind（语义种类）
文案在源码中的固定类别：脚本字符串、模板字面量、HTML 文本/属性/表达式、CSS generated content、静态 HTML 文本/属性。
Source range / location（源码范围 / 位置）
原始源码里的半开区间和其文件、种类组合；行从 1 开始、列从 0 开始，列以 UTF-16 code unit 计。
Resource snapshot（资源快照）
一个资源身份完整的收集结果；下一次同身份快照是“替换”，不是增量追加，所以删除的文案会消失。
Resource identity（资源身份）
项目相对路径加语义 block，例如 src/App.vue::template[lang=html]；同一 Vue 文件的不同 block 不互相覆盖。
Collection round（收集轮次）
一次 compilation 的候选收集；只有无错误、无键冲突且文件提交成功时才成为正式结果。

键、目录与翻译域

Hash collection output（哈希收集产物）
MD5(text) → text 的运行时字典及其 source map。相同文案按值去重，为旧消费者保持兼容；它不是翻译运行时键，也不能表达 occurrence identity。
Occurrence（出现）
源码中一次具体的文案出现；它有自己的位置，并可独立匹配、替换，但不一定等于一个翻译单元。
Localization key（本地化键）
翻译目录和源码替换使用的稳定键。显式 i18n-key 可以指定它；没有 directive 时，automatic key 首次按 occurrence 分配，并通过 catalog metadata/history 复用，而不是按当前文本或坐标重新推导。
Automatic key（自动键）
无显式 key 的 occurrence 获得的 localization key。可读 slug 只是诊断提示；若历史匹配不唯一，系统分配避开旧 key 的 proposed key，并等待确认。
Translation catalog（翻译目录）
按 locale 保存的 key → text 平面映射。收集写源语言目录；translate 写目标语言目录。相同文本的不同 occurrence 默认可以拥有不同 key。
Catalog metadata（目录元数据）
每个键的源文案、指纹、键来源、位置和 occurrence identity；用于恢复自动键、计算新增/删除/源码变化，并追踪 active/orphaned 生命周期。
Review state（审阅状态）
目标翻译所接受源指纹及 current/needs-review 状态，防止源文案变更时静默误认为翻译仍正确。
Translation provider（翻译提供方）
项目本地模块，输入待翻译项并返回 drafts/failures。包不内置厂商 SDK；会外发文案的提供方必须显式网络授权。

替换域

Replacement preview（替换预览）
replace 的默认结果：报告将要生成的源码，不写文件。
Source replacement（源码替换）
受适配器支持的位置才会改成现有运行时调用，如 t('key') 或 $t('key')；只有 --write 才提交。
Replacement adapter（替换适配器）
js、vue2、vue3 的调用形状与前置运行时集成契约。它不插 import、不安装依赖、不改启动代码。
记忆锚点：“文本”按值去重供旧字典使用；“键”标识翻译单元；“快照”控制一个资源的生命周期；“轮次”控制何时把候选结果正式发布。
