函数契约索引

面向改代码时的导航：按模块列出导出与关键内部协调函数，说明输入/结果/不变量。逐个 extractor 的小型扫描/AST helper 是实现细节，修改其行为时应从对应纯函数测试反推契约。

配置、范围、资源

函数契约 / 存在理由
config: validate把原始对象规范化为唯一合法 config；拒绝未知字段、跨根路径、重复项与产物碰撞，阻止错误沉入构建后期。
loadConfig合并 defaults → file → loader options → plugin options → collect overrides，返回 root、fileConfigHash、configHash；不同 hash 保证缓存安全且目录/翻译搬迁不扰动语义快照。
projectPath / filterList / normalizeFilterPattern约束路径和 patterns 在项目内且确定；是 validate 的输入安全层。
catalogFiles由 format extension 与 sourceLocale 得出 source catalog/meta 路径，避免路径规则散落各命令。
translationSettings只允许 translation fields 的临时覆盖，保留同一套 validate。
scope-pattern: isGlobPattern / normalizeGlobPattern / scopeMatches区分路径边界与受限 glob，验证后匹配；不用第三方隐式 glob 行为以稳定跨平台语义。
resource: containsHan / offsetToPosition分别负责 Unicode Han 资格与 CRLF/UTF-16 准确坐标。
describeResource从 path/query 得到 block、language、style index、source offset 和 stable identity；隔离 Webpack request 复杂性。
isResourceIncluded实现“任一 include 命中（空 include 全放行）且没有 exclude 命中”的最终 scope 规则。

指令与提取器

函数契约 / 存在理由
directives: whitespaceGap判定两个源码范围间是否仅空白，是“紧邻指令组”精确定义。
isExclusionDirective / isLocalizationKey识别 exact no-i18n-auto 与合法 key grammar；普通注释保持无语义。
scanDirectives扫描注释为结构化 directive，及早将 malformed key 锚定到评论位置。
directivesBefore只返回目标构造之前、仅以空白相隔的一组指令，禁止反向/跨代码关联。
keyDirective / keyConflict从一组指令取唯一 key，或在两个不同 key 指同片段时失败。
babelComments把 Babel comment 数据转换为共享 directive 形状。
contextSuppresses对一个脚本 AST path 判断选中的 logging/tests/analytics policy 是否压制；只认列出的静态 callee 形状。
extractScript解析 JS/TS/JSX、过滤 module specifier/context/directive，返回 string/template static entries；不执行代码。
extractVueScript定位 SFC script、保留换行并遮罩其他字符，再委托 extractScript，保证返回位置相对原 SFC。
extractHtmlparse5 document/fragment 解析，定位 Vue template，收集 text/attributes/interpolation/binding 静态 fragments，返回 entries/warnings 或可信性错误。
extractCss定位 CSS style block，用 PostCSS 找 content strings，解码值且保留 raw span；不支持语言返回 empty entries + warning。

Loader、Session、Plugin

函数契约 / 存在理由
loader: text / withoutRoot / canonicalPair分别统一 Buffer 文本、从 options 分离 root、规范 realpath 对；保证分派输入稳定。
vueFile / snapshotFor判断 SFC 与创建完整、可序列化 resource snapshot。
collectionFailure把 extractor 错误加上项目路径/block/style/lang/坐标，形成可操作 collection diagnostic。
trackConfig将 config 文件或 missing dependency 登记给 Webpack，使 watch 对创建/修改配置敏感。
record将 module metadata 与当前 session submission/invocation 同步；缓存恢复与本轮提交都依赖它。
publishWarnings借 session 按 code+identity 去重后才 emit warning，避免多次 loader 调用刷屏。
collectedFor / runCollect前者按资源 block 选择 extractor；后者执行完整 loader 收集协议，拒绝 thread-loader worker。
loader / loader.pitchpitch 从原文件收集并设去重标记；normal 阶段只作后备/透明 callback。
session: rootCompiler / mainCompilation归一 child compiler 与 child compilation 到主生命周期所有者。
moduleMetadata / interpretMetadata / assembleLiveSet写、验证、重建缓存 snapshot；schema/root/fileConfigHash 任一不合即诊断，防止跨构建污染。
retainStaticHtmlSnapshots / selectActiveHtmlTemplates在 HWP child cache 命中时有限保留有效 HTML 快照，同时在模板移除/缺失/超 scope 时淘汰。
CollectionSession.begin/round惰性创建一个 main compilation 的 candidate round。
noteInvocation / submit / warn分别记录 loader evidence、替换式 snapshot、去重 warning。
candidateSnapshots / committedSnapshots / abandon安全地读取 clone、暴露已提交 clone、或清空并封存失败 round。
commit / checkpoint / rollback / releaserelease 的小事务：保存内存检查点，commit，再写磁盘；任意 write 异常回滚内存且 abandon。
getSessionWeakMap 获取/创建 root compiler session。
plugin: configuredHtmlTemplates / activeHtmlTemplates从 HWP options 和 dependency graph 得到真实有效 template，不读 template 源。
separatedModules / snapshotsForRelease区分 main/child graph，合并可信 metadata 和本轮提交以产生发布候选。
catalogOutputs经 format adapter 序列化源 catalog 与 metadata，供 writeOutputs 一次提交。
MyI18nPlugin.apply注册 thisCompilation/afterSeal/done hooks，编排 round 验证、catalog conflict 和 transactional release。

聚合、输出、翻译

函数契约 / 存在理由
store: keyFor / normalizeLocation / uniqueLocations / sortLocationsMD5、位置 schema 校验、去重和确定性排序的基础原语。
CollectionStore.replaceSnapshot用一个资源的完整 entries 覆盖旧状态（含空快照），而非 append。
runtimeDictionary / sourceMap从所有 snapshots 产生稳定的兼容输出；前者按值、后者合并位置。
catalog: sha256 / fingerprintOf / pathSlug / automaticKey为 automatic key 和源演化建立可读 slug、首次 occurrence 的确定性候选以及 16 位 source fingerprint；导出的 deriveKey 只是兼容名称。
buildCatalog / matchAutomaticKeys / catalogMetadata / diffCatalog为每次 occurrence 分配或从 history 复用 key，处理 structural-anchor ambiguity、message-contract variants，产出 messages/meta 并比较新旧 source 指纹。
where / conflictMessage将跨资源 key conflict 变为包含每个位置的可修复诊断。
catalogFormat按 name 选择 format adapter；目前只允许确定性 JSON。
output: json / unchanged稳定 pretty JSON 与字节相同短路。
restoreCommit / recoverCommits按 journal 删除 temp、恢复 backup、清 journal；下次写入前先恢复未完成提交。
commitFiles / writeOutputs把任意一组文件以 temp/backup/journal 方式提交；writeOutputs 组装 collection 官方产物。
translate: cloneState / planTranslation复制 review state，并计算要请求、要保留、要标记的 pair 和拟写 catalogs。
applyDrafts仅接纳已请求的 provider outputs；验证文本，failure 优先，找出缺失 draft。
needsReview / serializeState列出需要人工审阅 pair，并确定性写 translation state。

CLI 与替换规划

函数契约 / 存在理由
main: write / main统一终端写入与四命令分发。
run: commandError / parseRunArgs / stageArgs验证 run 语法、只把 flags 发给其 owner stage、防止无 stage 的孤立 flag。
invoke / section / diagnostic / stageReport / run执行固定 stage 顺序、组装 human/JSON 输出并传播第一个失败。
replace-preview: offsetAt / fileClass / scopeReason将 catalog 位置定位回当前文件、归类支持面、给不可支持文件精确理由。
decodeHtml / matchesText重新验证 metadata 值与当前 raw/HTML-encoded 文本匹配，拒绝 stale edit。
looksLocalized / localizationAt识别已有 t/$t/this.$t，防止重复嵌套替换。
runtimeCalls / exportsLocalizationFunction探测 adapter 所需既有 runtime 调用/导出，替换从不自行安装它。
planPreview将 catalog locations 转为不重叠、已验证的 edit/skipped/already-localized/file previews；这是 dry-run 的核心安全边界。
修改纪律：若你改动上述任何契约，先找到同名模块的 unit test，再补上真实 Webpack/CLI 边界测试；函数内部的 helper 拆分可变，行为契约不可暗改。
