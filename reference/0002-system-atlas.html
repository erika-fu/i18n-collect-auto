公共入口与命令

文件入口 / 核心函数职责与理由
bin/i18n-collect.js可执行入口将进程参数交给 main，把未捕获异常归类为 build failure。
cli/main.jsmain, write唯一命令分发点；统一帮助、stdout/stderr 与退出码，避免各命令形成不一致的 CLI 壳。
cli/collect.jscollect在临时目录运行已有 Webpack 集成、禁止网络并生成目录差异报告；不复制一套扫描器。
cli/translate.jstranslate读取目录并安全调用项目提供方；收集与翻译解耦，故翻译不需要 Webpack。
cli/replace.jsreplace验证运行时前置条件、计划预览并仅在 --write 时提交。
cli/run.jsparseRunArgs, stageArgs, run将 flags 分桶并严格按 collect → translate → replace 执行，首个失败即停止，避免后续阶段消费不可信输入。

收集与发布

模块导出 / 核心函数为什么存在
myloader/index.jsloader, loader.pitch, runCollect, collectedFor, record透明 Webpack adapter：在 pitch 获取原始文件、分派 extractor、把快照写进 module metadata 与 session，但原样传递编译内容。
myplugin/index.jsMyI18nPlugin, snapshotsForRelease, activeHtmlTemplates只管 compilation 生命周期、缓存快照恢复、冲突检查和原子输出；刻意不读业务源码。
myloader/resource.jscontainsHan, offsetToPosition, describeResource, isResourceIncluded把 Webpack request 归一为稳定、可测试的资源分类、位置与身份。
myloader/extract-script.jsextractScriptBabel AST 静态提取字符串和模板段；不执行应用代码。
myloader/extract-html.jsextractHtmlparse5 分析 HTML/Vue template，保留原始范围而以解码值作为文案身份。
myloader/extract-css.jsextractCssPostCSS 仅处理标准 CSS 的 content 字符串；未知预处理器警告且跳过，不猜语法。
myloader/extract-vue-compat.jsextractVueScript从原始 SFC 对齐 script block 后复用脚本提取器，以换取精确原始坐标。
myloader/directives.jsscanDirectives, directivesBefore, keyDirective, keyConflict将 no-i18n-auto/i18n-key 的“前向、仅空白可隔开”关联规则统一给三类 extractor。
myloader/context-filter.jscontextSuppresses可选的明确策略，而非隐式猜测；仅压制已知日志、测试、分析调用里的脚本文案。

状态、产物与迁移

模块导出 / 核心函数为什么存在
mycommon/config.jsvalidate, loadConfig, catalogFiles, translationSettings单一配置权威；强制字段归属、根目录边界及不同 hash 的缓存语义。
mycommon/scope-pattern.jsisGlobPattern, normalizeGlobPattern, scopeMatches自定义受限 glob，拒绝含糊或越根模式，使跨平台语义稳定。
mycommon/session.jsCollectionSession, getSession, assembleLiveSet, retainStaticHtmlSnapshots以 root compiler 隔离轮次；缓存元数据恢复、HTML child compiler 保留、失败回滚皆在此。
mycommon/store.jsCollectionStore, keyFor, normalizeLocation, sortLocations按快照替换、MD5 兼容字典、位置校验/去重/稳定排序。
mycommon/catalog.jsautomaticKey/deriveKey, buildCatalog, matchAutomaticKeys, diffCatalog, fingerprintOf为每个 occurrence 分配或复用 automatic key；利用 semantic host、sibling context 和历史 metadata 恢复身份，在提交前阻止 ambiguity 与一个键对应不兼容的 message contract。
mycommon/catalog-format.jscatalogFormat输出格式的狭窄适配缝；现在只有确定性 JSON，未来可扩展而不污染核心流程。
mycommon/output.jsunchanged, recoverCommits, commitFiles, writeOutputs字节相同不写以使 watch 收敛；journal+临时文件+备份让多文件更新可恢复。
mycommon/translate.jsplanTranslation, applyDrafts, needsReview, serializeState纯翻译状态机，便于全面测试 partial/strict、重译和审阅状态。
mycommon/replace-preview.jsexportsLocalizationFunction, runtimeCalls, planPreview保守的源码编辑计划器：先验证当前源码坐标/文本和 runtime 能力，再产生互不重叠的 edit。
阅读方法：“所有函数”不等于逐行背诵。先掌握每一函数维持的契约与它所在层的边界；遇到修改任务再从本页定位文件、以测试反推边界条件。
