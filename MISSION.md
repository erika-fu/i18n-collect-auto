# Mission: Master i18n-collect

## Why
Build a working, implementation-level mental model of this repository so I can safely integrate, debug, extend, and review its internationalization collection workflow rather than merely operate its commands.

## Success looks like
- Trace any collected Chinese fragment from source resource through Webpack, catalog output, translation, and optional source replacement.
- Explain the responsibility, contract, and design rationale of every project module and its functions.
- Configure the package in a Vue 2 or React/Webpack 5 project, diagnose failures, and make bounded changes with appropriate tests.

## Constraints
- Teaching must be professional, easy to understand, concise without omitting implementation-relevant points.
- Lessons must be grounded in the checked-out code and its primary repository documentation.

## Out of scope
- General i18n theory unrelated to this repository.
- Unsupported build tools and replacement targets unless used to explain a deliberate boundary.
