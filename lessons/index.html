I18N-COLLECT · COMPLETE COURSE

从构建收集到安全迁移

目标是能接入、排错、扩展与评审这个项目，而非只会运行命令。每课约 5–10 分钟；先回答练习题，再显示答案。

学习路径

  1. 系统地图：四阶段、三种身份与整体边界。
  2. Loader 与提取器：原始源码、pitch、透明传递、纯模块分工。
  3. 提取语义：JS/Vue/HTML/CSS、指令、过滤和坐标。
  4. 配置与接入：字段所有权、hash、Webpack/Vue/HWP loader 顺序。
  5. Session、Plugin 与输出事务：缓存恢复、live set、journal 与 watch。
  6. Catalog 与本地化键：双轨输出、派生 key、冲突与 diff。
  7. CLI 与 collect：安全的一次性 Webpack collection 和 workflow 编排。
  8. 翻译状态机：provider、审阅状态、partial/strict 与网络授权。
  9. 替换预览与写入：adapter、skip、preview、strict、原子 write。
  10. 测试与掌握路径：测试分层、端到端链路与能力验收。

常驻速查

  • 术语表：用项目的规范语言讨论。
  • 系统与函数地图：按模块定位责任。
  • Webpack 接入速查：复制正确的 integration shape。
  • CLI 操作与退出码：命令边界、安全条件与排错入口。
  • 函数契约索引：逐模块理解导出与关键内部函数“做什么、为何存在”。

推荐节奏

第 1–5 课建立 collection 心智模型；第 6–9 课理解迁移工作流；第 10 课选择一个小变更完成“预测 → 写测试 → 验证”的闭环。间隔一天后重新作答第 1、5、8、9 课练习，优先练习回忆而非重读。

跟我继续学：每完成一课，把练习答案或你在源码中发现的矛盾告诉我。我会据此判断下一步，不把“已经看过”误记为“已经掌握”。
