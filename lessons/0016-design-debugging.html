NEW SERIES · 05 / 05 · DESIGN & DEBUGGING

这套 Loader 为什么这样设计？如何定位“没有收集到中文”？

最后一课把实现细节提升为可复用的设计原则，并给出一条从现象反推调用链的排错路径。

1. 四个核心设计思想

语义阶段收集
在 JS AST、HTML 节点、CSS declaration 仍然可辨认时收集，而不是扫描 final bundle。这样能保留“来自哪里”的 semantic kind 和原始位置。
观察与转换分离
Loader 观察源码但透明传递；源码替换是之后独立的 replace 命令。收集不会偷偷改变业务代码。
资源快照替换
每个 resource identity 提交完整 snapshot，包含空结果。这让删除文案、删除 block、改变 filter 都能被正确反映。
候选与正式输出分离
Loader 的结果先进入 candidate round，整个 Compilation、catalog 和文件写入都成功后才发布，避免部分结果污染仓库。

2. “没有收集到中文”的排错决策树

结果为空 ↓ Loader 是否进入请求链？ ├─ 否 → 检查普通 module rule、Vue block rule、HTMLWebpackPlugin forced chain └─ 是 ↓ resource identity 是否正确？ ├─ 否 → 检查 extension、?vue&type、style index/lang └─ 是 ↓ include/exclude 是否放行？ ├─ 否 → 检查 project-relative pattern；exclude 最终否决 └─ 是 ↓ 选择的 extractor 是否支持该语义？ ├─ 否 → 例如 SCSS/Less 或非 allowlist attribute └─ 是 ↓ 候选是否含 Han、是否被 directive/context filter 排除？ ├─ 是 → 这是预期的空 snapshot └─ 否 → 检查解析错误、位置和 Plugin round diagnostics

第一问永远不是“Plugin 为什么没扫到”，因为 Plugin 的职责本来就不是扫描。先确认资源是否真的进入 myloader。

3. 三类常见误解

误解正确模型
“中文相同就共享一个翻译 key”hash dictionary 按文本去重；catalog 默认按 occurrence 分配独立 localization key。相同文本可有不同翻译。
“行号就是 occurrence identity”行号只是 source location；自动 key 恢复依靠 metadata 中 structural anchor 和 occurrence identity。
“Loader 收集后 bundle 立即使用新 dictionary”一次构建结束后才写输出；同一次 bundle 可能仍内嵌构建开始时的旧 dictionary，watch 后续编译才看到新文件。

4. 用测试验证理解

理解调用链时，不要只读函数名，按契约选择测试：

  • loader.test.js：透明传递、metadata、空 snapshot、错误位置。
  • resource.test.js：query、identity、scope 和坐标。
  • script-extractor.test.js、html-extractor.test.js、css-extractor.test.js：纯提取语义。
  • webpack-integration.test.js：真实 Module graph、Vue block 和集成顺序。
  • watch-loop.test.js：输出变化后最多一次 follow-up compilation 并最终安静。

一个好的修改顺序是：先改对应纯 extractor 测试，再改 Loader adapter，最后补真实 Webpack 边界测试。

综合练习

下面的 Vue 文件中，哪些内容会进入收集结果？

<template>
  <button title="提示">欢迎，{{ name }}！</button>
</template>
<style lang="scss">.x::before { content: "装饰" }</style>
<script>console.log("调试中文")</script>

template 中的 title="提示" 是 allowlist attribute；“欢迎，”和“！”属于静态 HTML 文本片段（插值 name 不收集）。SCSS 不解析，产生 warning 和空 snapshot；script 中“调试中文”默认会收集为 script-string，只有配置 contextFilters: ['logging'] 时才被过滤。所有内容仍原样传递给后续 Loader。

整套课程的最终模型：Webpack 决定 Loader 何时看到资源；Loader 规范化资源并选择语义 extractor；extractor 只识别静态可证明的片段；snapshot 把单资源事实交给 Session；Plugin 在成功 round 中聚合并事务性发布。
